# SORA NO KOE｜FONT SSOT（FINAL）

## 0｜基本思想
フォントは「見た目」ではなく、役割で分ける。
同じ媒体でも、役割が違えばフォントも変えていい。
逆に、媒体が違っても役割が同じならフォントは揃える。

役割は3層だけ。

- Tier 1｜存在
- Tier 2｜記憶
- Tier 3｜余韻

---

## 1｜Tier 1：存在
**Font**
- Zen Kaku Gothic New

**役割**
- 構造を立てる
- 輪郭を出す
- 情報を認識させる
- 「いま何を見ているか」を一瞬で伝える

**用途**
- ロゴ
- サイト名
- セクション見出し
- OGPタイトル
- IG 1枚目の主役文字
- カルーセルの天体名
- PDF表紙
- ボタンやUIラベル
- 数字・日付

**向いているもの**
- 太陽 / 月 / 天体名
- 日付
- 構造タイトル
- 接点のラベル
- CTAの主見出し

**使い方**
- 大きく使う
- 太さで階層を出す
- 文字間は少しだけ広めでもよい
- 情報の骨格に使う

---

## 2｜Tier 2：記憶
**Font**
- Shippori Mincho

**役割**
- 意味を沈める
- 言葉を残す
- 読む時間をつくる
- ソラのこえの本文の深さを担う

**用途**
- ブログ本文
- IG / OGP / PDF の本文
- 共鳴の説明文
- つきじの本文
- Blueprint本文
- LP本文
- 解説テキスト

**向いているもの**
- 観測文
- 余韻を含む説明
- 「静かな意味」
- 読ませる文章

**使い方**
- 長文はこれを基本にする
- 行間は広め
- 小さすぎるサイズでは使わない
- ゴシックより一段静かに見せたい時に使う

---

## 3｜Tier 3：余韻
**Font**
- Klee One

**役割**
- 空気を残す
- 注釈や小さな温度を足す
- 主張しないけれど、世界観を支える

**用途**
- 注釈
- 補足
- 小見出し
- ハイライトの短文
- 「解釈は、あなたのもの。」
- 小さな案内文
- 余白の一文
- CTA下のサブ文

**向いているもの**
- 詩的な一文
- 補助テキスト
- 呼吸を作る言葉
- 余白文

**使い方**
- 小さめで使う
- 主役にしない
- 多用しない
- ひとつ入ると空気が柔らかくなる場所だけに使う

---

## 4｜媒体別の適用ルール
**Web / Blog**
- 見出し：Zen Kaku Gothic New
- 本文：Shippori Mincho
- 注釈 / 補足：Klee One

**IG Carousel**
- ロゴ / タイトル / 天体名 / 日付：Zen Kaku Gothic New
- 本文 / 共鳴説明 / つきじ説明：Shippori Mincho
- 小見出し / 補助文 / 余韻：Klee One

**OGP**
- メインタイトル：Zen Kaku Gothic New
- サブコピー：Klee One or Shippori Mincho
- 長文は入れない

**PDF / Blueprint**
- 表紙 / 章タイトル / 数字：Zen Kaku Gothic New
- 本文：Shippori Mincho
- 注釈 / 小さな余白文：Klee One

**LINE画像 / アイキャッチ**
- 構造タイトル：Zen Kaku Gothic New
- 本文がある場合：Shippori Mincho
- 短い余白文：Klee One

---

## 4.5｜IG Typography SSOT（1080px）
H1 タイトル（例：☉ 太陽｜山羊座）
Zen Kaku Gothic New / 120px / letter-spacing 0.02em / line-height 1.2

H2 セクション（例：今日の共鳴、つきじ、sky chart）
Zen Kaku Gothic New / 44px / letter-spacing 0.12em / line-height 1.3

H3 天体表示（例：♀ 金星（山羊座））
Zen Kaku Gothic New / 72px / letter-spacing 0.04em / line-height 1.4

サブ情報（例：セクスタイル 60° / orb 0.29°）
Zen Kaku Gothic New / 32px / letter-spacing 0.06em / line-height 1.4

本文
Shippori Mincho / 40px / letter-spacing 0.02em / line-height 1.9

補助テキスト（観測文など）
Klee One / 34px / letter-spacing 0.04em / line-height 1.6

メタ情報（日付 / Swipe）
Zen Kaku Gothic New / 28px / letter-spacing 0.12em / line-height 1.4

CTA タイトル
Zen Kaku Gothic New / 96px / letter-spacing 0.02em / line-height 1.25

CTA サブ
Klee One / 40px / letter-spacing 0.04em / line-height 1.6

余白ルール
外側余白 120px
本文横幅 720px
段落間 40px
セクション間 100px

---

## 5｜禁止ルール
- 本文を全部ゴシックにしない
- 注釈を強いゴシックで出さない
- Klee One を長文本文に使わない
- Shippori Mincho をUIラベルに使いすぎない
- 1画面で3フォント全部を強く主張させない

---

## 6｜優先順位
迷ったらこの順で決める。

- 構造 = Zen Kaku Gothic New
- 意味 = Shippori Mincho
- 余韻 = Klee One

---

## 7｜ひとことで定義
- Zen Kaku Gothic New = 存在の輪郭
- Shippori Mincho = 記憶に沈む言葉
- Klee One = 残響

---
